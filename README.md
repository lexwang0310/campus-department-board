# 🎓 Campus Department Board

一个面向大学院系的在线留言与交流平台。

帮助学生快速获取课程信息、考试经验、实习资源和院系通知，打造院系内部高质量知识共享社区。

---

## ✨ 项目简介

Campus Department Board（院系留言板）是一个基于 Next.js + Supabase 构建的现代化校园社区平台。

学生可以：

- 发布院系相关帖子
- 浏览课程经验
- 分享学习资源
- 讨论考试内容
- 获取实习就业信息
- 收藏优质内容
- 与同院系同学交流互动

项目采用 Serverless 架构设计，支持快速开发与部署。
